
Este repositório contém a Super Base Tensor 1D, um conjunto de dados multimodal projetado para o treinamento de modelos de Aprendizado de Máquina (como XGBoost, Transformers e Redes PINNs) aplicados à manutenção preditiva de infraestruturas ópticas.

O dataset resolve o problema da fragmentação de dados na literatura de telecomunicações ao fundir cinco fontes públicas heterogêneas (traços de OTDR, telemetria de rede, ensaios mecânicos laboratoriais e clima histórico) em um único enlace sintético multimodal, refletindo o estresse termomecânico e a degradação de cabos de aterramento óptico (OPGW).
